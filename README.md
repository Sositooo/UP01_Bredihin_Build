## О проекте
WPF-приложение «Build» для сервиса аренды строительной и специальной техники.
 
- **Клиент** просматривает каталог техники с фотографиями: поиск, фильтр по категории и состоянию, сортировка по цене.
- **Администратор** (менеджер по аренде или бухгалтер) управляет пользователями, категориями и техникой, смотрит диаграммы и выгружает отчёты в Word, PDF и Excel.
Остальные таблицы базы данных реализуют напарники по курсовому проекту.
 
**Технологии:** C#, WPF, .NET Framework 4.8, навигация Page + Frame, Entity Framework (ADO.NET Entity Data Model, Database First), Microsoft SQL Server.

## База данных
10 таблиц: `Roles`, `MachineCategories`, `Users`, `Clients`, `Machines`, `RentalRequests`, `RequestItems`, `Contracts`, `Payments`, `HandoverActs`. Связи заданы внешними ключами.
 
В приложении реализована работа с таблицами `Users`, `MachineCategories` и `Machines` (и справочником `Roles`). Фото техники хранится в виде ссылки в столбце `Machines.PhotoUrl`.
 
## Что реализовано
- Авторизация и регистрация с ролями «Пользователь» (Клиент) и «Администратор» (Менеджер по аренде, Бухгалтер)
- Проверка введённых данных, ограничения ввода символов, минимальные и максимальные значения чисел
- Хранение паролей в виде SHA1-хэша
- Капча после трёх неверных попыток входа
- Смена пароля
- Страница пользователя: просмотр, поиск, фильтрация, сортировка
- Страница администратора: то же, а также добавление, редактирование и каскадное удаление (с подтверждением) данных таблиц `Users`, `MachineCategories`, `Machines`
- Диаграммы (6 типов) и экспорт отчётов в `.docx`, `.pdf`, `.xlsx`
- Две темы оформления (по Руководству по стилю и собственная зелёная); выбор сохраняется после выхода и перезапуска
- Динамические заголовки страниц, плейсхолдеры, всплывающие подсказки, подтверждение выхода и удаления
- Единые стили: шрифт Open Sans, одинаковый размер кнопок
## Как запустить
1. В SQL Server Management Studio выполнить `db/schema.sql` (создаст базу `ConstructionRentalDB`).
2. Открыть `Build.sln` в Visual Studio.
3. Добавить в проект модель **ADO.NET Entity Data Model** (EF Designer from database): отметить все 10 таблиц, снять галочку «Pluralize», имя строки подключения указать **`BuildEntities`**.
4. Проверить строку подключения в `App.config` (имя сервера SQL Server на вашем компьютере).
5. Запустить проект (F5).

## Фото техники
Откройте таблицу техники → «Редактировать» → в поле «Ссылка на фото» вставьте прямую ссылку на изображение (`https://...jpg`). Либо выполните в SSMS:
 
```sql
UPDATE Machines SET PhotoUrl = N'https://...' WHERE InventoryNumber = N'EX-001';
```
